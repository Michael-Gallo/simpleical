# RFC 5545 Extracted Sections

Source: `../rfc5545-icalendar.txt`

This directory splits the RFC 5545 iCalendar specification into smaller Markdown files for targeted agent/context retrieval. The original text file remains the canonical full copy.

## Directories

- `components/`: VCALENDAR and component definitions.
- `properties/`: Calendar and component property definitions.
- `parameters/`: Property parameter definitions.
- `value-types/`: Property value data type definitions.
- `sections/`: Larger specification sections and grouped overviews.
